# Support

![Speed of Sound](assets/logo-square-512.png){ width=250 }

If you run into any issues, have questions, or need troubleshooting help, please open a ticket on the
[GitHub issues page](https://github.com/zugaldia/speedofsound/issues). Pull requests are also welcome.

## Including debug information

When reporting an issue, please include the debug information from the app. This helps identify your
runtime environment and system configuration, which makes troubleshooting easier.

To find it, open the **About** dialog (from the menu in the main window), then go to the
**Troubleshooting** section. You can copy the debug information to your clipboard or save it to a file
directly from that page. Please paste it into your issue report.

The debug information looks like this:

```
Speed of Sound v1.2.3

Runtime: JVM
Data directory: /home/user/.local/share/speedofsound
Temporary directory: /home/user/.local/share/speedofsound/tmp

OS: Linux 6.18.7-76061807-generic
Architecture: amd64
Java: 25.0.2 (Ubuntu)
Kotlin: 2.3.10
```

## Contributing

Speed of Sound is in [maintenance mode](faq.md#is-speed-of-sound-still-maintained), so contributions are
limited to bug fixes and compatibility updates (for example, new distribution releases, desktop environment
changes, or dependency updates). Pull requests that add new features or make large changes will likely be
declined, so if you're unsure whether something fits, please open an issue to discuss it before writing code.
